# MarkItDown Studio

Universal in-browser document to Markdown studio powered by client-side WebAssembly parsers (`pdf.js`, `mammoth.js`, `sheetjs`, and `turndown.js`).

## Features
- **100% Client-Side:** All files (PDF, Word, Excel, CSV, HTML, Text) are converted entirely inside your browser. No files are uploaded to any server.
- **Offline & PWA:** Installable as a standalone progressive web app on Android (Samsung Galaxy S24 Ultra) and Desktop.
- **Native Android Share:** 1-tap share directly to Samsung Notes, WhatsApp, or Google Drive.
- **Hosted on GitHub Pages:** Runs 24/7 with zero downtime and fast global CDN distribution.
